# Command: /deep-bagu

## 用途

调用 `.codebuddy/skills/deep-bagu/SKILL.md`，先给简短结论，再给可运行示例与可断点源码链路。

## 触发方式

1. 显式输入：`/deep-bagu <问题>`
2. 消息包含：八股、Interview、JVM、GC、并发、AQS、MySQL、Redis、Spring、分布式、底层原理、源码、调优、排查
3. 在问经典技术知识点，且希望看到机制级解释

## 执行步骤

1. 读 `.codebuddy/skills/deep-bagu/SKILL.md`，按规则执行，不凭记忆套模板。
2. 判档：只问"是什么/区别"→ L1；问"怎么实现/为什么生效"→ L2；要求源码级、打断点、看调用栈 → L3。判据见 SKILL.md 第 3 节。
3. 输出：L1 用四段式；L2/L3 用 SKILL.md 第 5 节模板 `0. 一句话结论` ~ `6. 落地与命令`，纯概念题可省略第 6 节。
4. 原理必须落到示例：最小可运行代码 + `// BREAKPOINT` + 观察变量；源码给类名、方法名、断点条件、预期调用栈，不写行号。
5. 按 SKILL.md 第 6 节质量闸门自检后输出。

## Demo 创建

默认不建文件，只在回答里贴代码。

仅当用户明确说"建 demo""给我能打断点的代码"时，按 SKILL.md 第 5.1 节创建；一次请求只建一个，位置默认 `c:/Workspace/spacex/suibianwanwan/suibianwanwan`。

## 输出约束

- 不写"实战故障现场"独立章节，故障内容并入"常见坑与误判"。
- 不伪造日志、源码行号、默认值、压测数据、事故案例；不确定处写"需按版本确认"。
- 危险命令附风险提示与低峰期/审批/回滚条件。
- 不展示真实连接串、密码、用户数据、内部域名。
- 先短后长：第 1 节不超过 5 行，不堆源码充深度。

## 使用示例

| 输入 | 档位 | 预期 |
|---|---|---|
| `/deep-bagu 解释一下什么是 TLAB` | L1 | ≤40 行，结论 + 机制 + 验证参数 + 一个坑 |
| `/deep-bagu Spring 循环依赖是怎么解决的` | L2 | ≤120 行，三级缓存 + 可运行示例 + 断点表 + 坑与追问，不建文件 |
| `/deep-bagu 我要打断点看三级缓存，建个 demo` | L3 | ≤250 行，完整模板 + 项目内 demo + 文件清单/断点/预期输出 |
| `/deep-bagu AQS 的 CLH 队列怎么工作` | L2 | 示例只贴在回答里，不建文件 |
