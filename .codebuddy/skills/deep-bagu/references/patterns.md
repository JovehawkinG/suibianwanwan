# 常见坑、误判与反例

用于填写模板第 4 节"常见坑与误判"，不要整节复制进输出。

## 1. 常见误判

| 现象 | 容易误判为 | 更可能的根因 | 验证方式 |
|---|---|---|---|
| 接口周期性变慢 | CPU 不足 | GC 停顿、safepoint、锁竞争 | GC 日志、`jstat`、线程栈 |
| 连接池耗尽 | 慢 SQL | 连接泄漏、事务过长、下游阻塞 | 连接池指标、线程栈、慢日志 |
| Redis 集群抖动 | 集群容量不足 | 热 key、大 key、慢查询、网络 | `INFO`、`slowlog`、key 采样 |
| 线程池队列堆积 | 下游接口慢 | 核心线程不足、队列无界、拒绝策略不当 | 线程池指标、任务耗时、线程栈 |
| 元空间增长 | 堆内存泄漏 | 动态类生成、代理膨胀、类加载器泄漏 | `jcmd GC.heap_info`、类加载统计、MAT |
| Redis 内存上涨 | 数据量增长 | 内存碎片、过期策略、复制缓冲区 | `INFO memory`、碎片率、过期键统计 |
| MySQL 偶发超时 | 慢查询 | 锁等待、间隙锁、事务隔离级别 | `innodb status`、锁等待表、执行计划 |
| 重试后雪崩 | 容量不足 | 重试风暴、超时设置不合理、缺少熔断 | 重试指标、链路追踪、压测 |
| Spring 启动变慢 | 机器性能 | 后置处理器提前实例化、循环依赖、`@PostConstruct` 阻塞 | 启动日志、`ApplicationStartup`、线程栈 |

## 2. 常见问题模式

| 模式 | 触发条件 | 典型表现 |
|---|---|---|
| 堆 OOM | 大对象、缓存无界、批量加载 | `Java heap space`、频繁 Full GC |
| 元空间 OOM | 动态代理、字节码生成、热部署 | `Metaspace`、类加载器无法回收 |
| 直接内存 OOM | Netty 池化、`DirectByteBuffer` 未释放 | `Direct buffer memory` |
| 线程耗尽 | 线程池无界、阻塞调用 | `unable to create new native thread` |
| 死锁 | 加锁顺序不一致、事务边界过长 | 线程 BLOCKED、`Deadlock found` |
| 连接泄漏 | 流未关闭、事务未提交 | 连接池活跃数持续上升 |
| 缓存击穿 | 热 key 过期、无互斥重建 | 数据库瞬时压力飙升 |
| 重试风暴 | 无退避、无幂等、无熔断 | 下游被打满、错误率放大 |
| 循环依赖 | 构造器互依赖、字段注入成环 | `BeanCurrentlyInCreationException` |

## 3. 反例

### 反例 1：只列概念

问题：只写名词，没有示例、参数、观察点。  
修正：补最小可运行代码、断点位置、观察变量，以及一个可执行验证方式。

### 反例 2：默认值无版本

问题：写"默认值是 X"，未注明 JDK / MySQL / Redis / Spring 版本。  
修正：标注版本；不确定时写"需按版本确认"。

### 反例 3：伪造日志与行号

问题：编造具体日志、精确源码行号、压测数据。  
修正：日志标明"示例结构"；源码只给类/方法/断点条件，不写行号。

### 反例 4：安全与回滚缺失

问题：直接给生产 dump、`KEYS *`、全表扫描、详细追踪，或只给参数不给回滚。  
修正：补风险、低峰期、审批、限时、脱敏，以及基线、灰度、观察指标、回滚条件。

### 反例 5：示例不可运行

问题：代码缺 import、缺配置、缺启动类，读者无法直接跑起来。  
修正：给完整 import 与必要配置；超过 40 行时只留关键片段，并注明可索取完整 demo。

## 4. 输出前对照

- 坑是否写成"看起来像 A，实际是 B"。
- 每条坑是否给了验证方式或规避方式。
- 是否只保留与当前主题相关的坑，没有堆通用建议。
