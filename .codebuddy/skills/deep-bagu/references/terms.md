# 表述与脱敏检查清单

本文件是 SKILL.md 第 8 节的扩充词表，供输出前自查使用。检查对象是最终输出文本，不检查内部推演过程。

## 1. 分类定义

| 类别 | 判定标准 | 处理 |
|---|---|---|
| 求职考核类 | 指向求职、考核、刷题场景的字眼 | 替换为技术表述，或整句删除 |
| 背诵机械类 | 指向机械记忆、应试技巧的字眼 | 替换为"记住结论"或删除 |
| 答题口吻类 | 以答题、作答、话术组织行文的表述 | 改写为排查思路、工程实践 |
| 夸大承诺类 | 绝对化、保证式结论（一定、必然、彻底解决、100%） | 改为带条件的表述，补适用版本与场景 |
| 伪造细节类 | 具体到行号、真实日志、精确压测数值却无来源 | 降级为"示例结构"或改为机制路径 |
| 危险操作无提示类 | 直接给 dump、全量扫描、`KEYS *`、生产 DDL 等命令 | 补风险提示与低峰期/审批/回滚条件 |
| 变更缺回滚类 | 只给参数或索引变更，不给基线与回滚 | 补基线、灰度比例、观察指标、回滚条件 |
| 内部敏感信息类 | 真实域名、连接串、账号、工号、项目代号 | 直接删改，不保留原值 |

## 2. 常见词条

求职考核类：面试、面经、offer、简历、刷题、背题、考点、大厂、三面、二面、HR 面。

背诵机械类：八股、八股文、背下来就行、背诵、默写、套模板答题。

答题口吻类：怎么答、如何回答、这样回答、答出深度、答题思路、加分项、亮点回答。

夸大承诺类：一定、必然、彻底解决、百分百、绝对安全、永不宕机、万能方案。

伪造细节类：具体行号、真实线上日志、精确到小数点的压测数据、未注明来源的事故案例。

危险操作无提示类：`KEYS *`、`jmap -dump` 无审批、`jmap -histo:live` 高频、生产 `ALTER TABLE` 无低峰期、`Arthas trace` 不限时。

变更缺回滚类：只调 `-Xmx`、只加索引、只改隔离级别，却没有观察指标与回退路径。

内部敏感信息类：内网域名、数据库连接串、账号密码、真实用户标识、内部项目代号。

## 3. 中性替代表述

- 求职考核类 → `Interview` 或直接省略主语。
- 背诵机械类 → 底层原理、核心机制。
- 答题口吻类 → 排查思路、工程实践、生产落地建议。
- 夸大承诺类 → 加条件："在该版本与数据量下通常表现为……"。
- 伪造细节类 → "示例结构""关键机制路径""需按版本确认"。
- 内部敏感信息类 → 占位符 `host:port`、`<db>`、`<user>`。

## 4. 自查流程

1. 通读标题、表格、代码注释、小结，逐段扫描，避免只看正文首段。
2. 命中第 1 节任一类别，按第 3 节替换；无法自然替换的整句删除。
3. 命中内部敏感信息类，先删改再输出，不保留原值做对照。
4. 自查只报告类别与位置，不在输出中复述命中的禁用词。
5. 同一段命中多类时，优先保证技术信息完整，再处理措辞。

## 5. 维护要求

- 新增词条先归类，再补到第 2 节对应行。
- 高频替换项同步进 SKILL.md 第 8 节表格，本文件只做扩充。
- 分类名称必须与 `tests/cases.yaml` 的 `forbidden_categories` 保持一致。
- 本文件只在自查时读取，不整体复制进输出。
